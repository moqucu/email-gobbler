# email-gobbler

A Swift package for extracting Schoology weekly overall grades and validating
and updating weekly grade rows. See the [SchoologyDomain documentation](SchoologyDomain/README.md)
for its API, requirements, and current scope.

Run the tests from `SchoologyDomain` with `swift test`. The Swift mail preview
can read a Schoology `.eml` file or the newest matching message in macOS Mail;
see the package documentation for commands.
